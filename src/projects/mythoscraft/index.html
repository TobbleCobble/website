Project Case Study

MythosCraft

Overview

I managed and collaborated with a team of programmers to develop a custom plugin framework for a large-scale Minecraft server. The goal was to create a modular system that allowed for rapid content iteration.

I was responsible for designing the Java framework using Maven and managing the release cycles via GitHub. This role required balancing technical architecture with team leadership and project timelines.
