Project Case Study

Sumo Battle Bot

Overview

Using an ESP32 as the base of the bot, as a team of 4 we built a sumo battle bot that placed 2nd in a competition of 50 different teams in a double elimination style tournament.

We integrated multiple control schemes including PID for motor synchronization and a Bang-bang controller for target locking. The project involved iterative 3D printing and rigorous testing to optimize weight distribution and traction.

Technologies Used

ESP32 C++ PID Control Autodesk Fusion 3D Printing

Key Outcomes

  • ● 2nd Place / 50 Teams
  • ● Sub-100ms Target Acquisition
  • ● Optimized 3D-printed Traction
